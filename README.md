# ياسم v0.9 — Wake Word preparation

هذه النسخة تفصل بين مرحلتين:

1. **Wake Word**: الاستماع لكلمة التنبيه.
2. **Command STT**: بعد اكتشاف التنبيه، يبدأ التعرف على الأمر ثم ينفذه.

## لماذا لم أضع محرك Wake Word جاهزًا داخل المشروع؟

محركات مثل Picovoice Porcupine تدعم Android وتعمل محليًا على الجهاز، وتحتاج AccessKey وملف keyword مخصصًا. الوثائق الرسمية تذكر أن الملف المخصص يوضع في `assets` وأن التطبيق يمكنه تشغيل المحرك في الخلفية، مع بقاء إمكانية التشغيل في الخلفية خاضعة لقيود نظام Android.

الأهم: قائمة اللغات الحالية في وثائق Porcupine لا تتضمن العربية؛ لذلك لن أدّعي أن كلمة «ياسم» العربية ستعمل كـ wake word مخصص بمجرد إضافة المكتبة. نحتاج اختيار محرك/نموذج يدعم العربية أو استخدام صيغة wake word مدعومة.

## الحالة الحالية

- ياسم v0.8 يعمل كنسخة تجريبية باستخدام SpeechRecognizer.
- v0.9 يجهز البنية للانتقال إلى Wake Word حقيقي.
- لا يوجد AccessKey مخزن داخل المشروع.
- لا تضع أي AccessKey في GitHub أو داخل ملف APK علنًا.

## الخطوة التالية

عند اختيار محرك يدعم كلمة التنبيه العربية، نربطه بالخدمة كالتالي:

Wake Word Engine → اكتشاف «ياسم» → تشغيل SpeechRecognizer → تنفيذ الأمر → العودة لوضع الاستماع.
